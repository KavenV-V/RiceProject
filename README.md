# **RiceProject** 🌾💰  
📌 *ระบบจัดการรายรับ-รายจ่ายของโรงสี(งานกลุ่ม 10 คน)*  

## 📖 **เกี่ยวกับโปรเจค**  
RiceProject เป็นระบบที่ช่วยจัดการรายรับ-รายจ่ายของโรงสี เพื่อลดข้อผิดพลาดจากการบันทึกแบบกระดาษ เช่น การบันทึกผิด, ข้อมูลไม่ครบ หรือเอกสารสูญหาย ระบบนี้ช่วยให้การบันทึกและตรวจสอบข้อมูลสะดวกและแม่นยำขึ้น  

## 🚀 **ฟีเจอร์หลัก**  
- **บันทึกข้อมูลรายรับ-รายจ่าย** พร้อมรายละเอียด (จำนวนเงิน, วันที่, ประเภทค่าใช้จ่าย)  
- **ค้นหาและแสดงผลรายการรายรับ-รายจ่ายย้อนหลัง**  
- **สรุปรายงานการเงิน** รายเดือน/รายปี  
- **ลดความผิดพลาดจากการจดบันทึกแบบกระดาษ**  
- **มีระบบสะสมคะแนน** สำหรับลูกค้าที่เป็นสมาชิก  
- **มีหน้าแดชบอร์ด** สำหรับเจ้าของโรงสีเพื่อติดตามภาพรวมทางการเงิน  

## 🔧 **เทคโนโลยีที่ใช้**  
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  

## 🛠 **การติดตั้งและใช้งาน**
